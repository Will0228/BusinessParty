# 接待カートレース

`settai_kart_race_spec.md` v0.2 のP1を中心に、既存ホームから起動するインゲームをカートレースへ変更しました。旧譜面・リズムゲームのエディター／モデルは既存データのため残していますが、インゲームからは使用しません。

## 起動

`Assets/Scenes/SampleScene.unity` を開き、Playしてホームの開始ボタンを押します。説明画面でEnter、SYNCまたは「接待を始める」を押すと3秒カウントダウン後にスタートします。失敗・成功画面でR／Enter／ボタンから再挑戦、Escまたはホームボタンで戻れます。

シーンの手作業は不要です。既存のGameView参照とスクリプトGUIDを維持し、コース・カート・HUDを実行時に生成します。参照が未設定の別シーンでは `MixVerse > Setup > Ensure Kart Game Screen` で接続できます。

## 操作

| 操作 | キーボード | DJコントローラー |
|---|---|---|
| 速度調節 | W/S または上下（GAIN値を増減） | BデッキGAIN |
| 左右へ操舵 | A/D または左右 | クロスフェーダー |
| 前進・後退切替 | X | MASTER GAIN |
| ドリフト | Q/Eを押し続ける | ジョグを回し続ける |
| アイテム | Space | SYNC |
| 煽り判定範囲 | Tab | — |
| ホーム | Esc | — |

初期GAINは50%。ブレーキはSでGAINを下げます。0%でも即停止せず減速します。ジョグ停止・逆回転でターボを解放します。速度表示は仕様書の相対速度値で、km/hではありません。

GameViewの`Midi Mapping`でチャンネル（0は全チャンネル）、各CCとノート番号を変更できます。仮マッピングはGAIN CC24、MASTER CC7、操舵 CC10、ジョグ CC27、SYNC Note60です。機種の確定値ではありません。MASTERは0.35未満で後退、0.65超で前進、中間では直前の方向を保持します。ジョグは標準でtwo's complement型相対値、`Binary Offset Jog`で64中心の形式に変更できます。0.16秒入力が途切れるとドリフトを解除します。Minisでホットプラグに対応しています。

## レースと接待判定

- 1200mの一本道を6区間に分けています。カートはコース距離＋左右位置で走行し、CPUはコースに追従します。上司は50、上りは44、部下は70、自車はGAINに応じて最大100です。
- 上司への接触、自分のロケランへの巻き込み、自分の書類による上司のスピンは即失敗です。
- 上司の真後ろ7m以内・左右差1.6m以内に3秒居続けると煽りで失敗。Tabで範囲を表示します。
- 自車／部下のどちらかが上司からコース距離で95m以上離れると失敗。前後両方が対象です。
- ギャラリーでは後退・壁衝突・スピン・横転が失敗。部下への攻撃自体は免除します。
- 部下が1位のときに失言。無線通知音と字幕で知らせ、10秒以内に攻撃が必要です。
- 上司が最初にゴールし、自車または部下が3秒未満で続けば成功。ゴール通過時刻は固定ステップ内で補間します。未到着でも3秒を過ぎれば失敗します。

通常走行入力だけで全コースをクリアする回帰テストを含めています。序盤は加速して部下の前へ出て減速し、上司を前へ通します。上司との横間隔を保ち、最後は自車か部下を3秒以内に続かせます。

## 攻撃とアイテム

- ブロッキング：部下の前8m以内・左右差1.45m未満で部下を70未満へ減速させる状態が0.65秒続くと成立。部下は追い越しを試みます。
- 押し出し：側面接触の2秒以内に部下が箱へ衝突した場合のみ成立。単なる接触／後方接触は攻撃になりません。
- 書類：後方3mに設置、14秒残留、踏むと1.4秒スピン。自分の書類で部下がスピンすると成立。
- ロケラン：前方へ直進、着弾すると半径4.5mを巻き込み2.2秒停止・横転。箱を破壊。上司の巻き込みも判定します。
- ドリンク：3秒加速。自車は最高120・加速度1.5倍、上司は巡航1.2倍、部下は70を超えません。
- アイテムは1つまで。色付きボックスの「書／弾／飲」で内容を識別できます。CPUも取得・使用します。

## 設定と構成

未決定パラメーターはGameViewの`Race Settings`へ集約しています。MVPパターンでGamePresenterがIGamePresenterを実装し、GameViewは表示と入力イベントの橋渡しを担当。KartRaceはUnity非依存で、1/120秒の固定ステップでルールと走行を計算します。KartStageFactoryとKartInputReaderはVContainerで注入します。
