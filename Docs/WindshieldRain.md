# フロントガラスの水滴

`Assets/Resources/RainWindshieldShaderURP.shader` を、既存の `KartWindshieldRainView` の全画面 RawImage で使用する。
`_RainAmount` によるトンネル内外のフェードは従来どおり。

## 表現

- 画面内の水滴はすべて流れる。列ごとに基準速度を変え、雨粒ごとに加減速の周期・位相と蛇行の周期・位相を変える。下向きの移動を保ったまま、速度と進行方向が連続的に変化する。
- 水滴の半径はセルごとにランダムに選び、小粒を多めにする。初期値は従来より小さい0.03〜0.14セル。
- 滴の上側に、細くなる流れ跡を生成する。上下左右の隣接セルも評価して境界で滴や尾が途切れないようにする。
- 曲面の高さと傾きから法線を生成し、水の屈折率1.333で背景UVを変位させる。
- フレネル反射と斜めのハイライトを加え、従来の白い中心・一律に明るい縁を抑える。
- 水滴の輪郭を画面解像度に応じてぼかし、背景の参照位置をテクセルの内側に制限する。

乱数は雨粒のIDから生成し、移動中やセル境界で再抽選しない。Fall Speedを0にすると、加減速と蛇行を含めて流れる滴が停止する。

CPUで粒子やテクスチャを毎フレーム更新せず、1パスで計算する。水滴がある画素のみ背景を2回参照する。流れる滴は境界を含む3×3セルを評価するため、従来の2セル評価より演算量が増える。

## 調整

| プロパティ | 用途 |
| --- | --- |
| Droplet Min Radius / Max Radius | 流れる水滴の最小・最大半径（横方向セル単位） |
| Size Variation | 大きさのばらつき。0で半径を一定に、1で最大のばらつき。小粒を多めに生成 |
| Streak Density X / Y | 流れる水滴の列数・縦方向の個数 |
| Streak Coverage | 流れる水滴の出現割合 |
| Fall Speed | 落下速度。0で流れる滴を停止 |
| Speed Variation | 速度のばらつき。0で一定、1で列の基準速度が0.3〜1.7倍になり、各滴の加減速も最大 |
| Direction Variation | 左右への蛇行の強さ。0でWind Skewに沿った直線、1で最大 |
| Wind Skew | 流れる方向の傾き |
| Trail Length | 流れ跡の長さ。0で無効 |
| Refraction Strength | 背景の歪みの強さ |
| Surface Curvature | 法線の傾きの強さ |
| Highlight Intensity / Power | ハイライトの強さ・鋭さ |
| Rain Amount | 演出全体の表示量。0で完全に透明 |

## 描画上の前提

URPのOpaque Textureが必要。現在の画面全体を対象とするRawImage向けであり、背景はカメラの不透明描画結果を使用する。
透明パーティクルやCanvasの文字は屈折元に含まれない。HUDの前面に置くと、その位置のHUDを水滴で覆う場合がある。
反射は画面内の背景による近似であり、画面外の環境反射、実際の水滴同士の質量を伴う合流、物理流体シミュレーションは行わない。
モバイル実機でのGPU負荷は別途測定する。
